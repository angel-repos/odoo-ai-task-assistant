AI Task Assistant

Automatically enriches every Project task with an AI Summary and sub-tasks when you assign a user to the task.

Features

  • AI Summary — A short summary generated by an LLM explaining what the task creator is asking for.
  • Auto sub-tasks — A list of concrete, actionable sub-tasks generated by AI and assigned to the same user as the main task.
  • Trigger on assignment — As soon as you assign someone to a task, the backend is notified and processing starts asynchronously.
  • Re-run — You can manually trigger “Re-run AI Analysis” from the task form at any time.

Configuration

Go to Settings → AI Task Assistant and set:

  • Activate license — Click "Activate free license" to register and get your API key (backend at https://odoo.lokeai.es).
  • Odoo URL for callback — URL the backend uses to reach Odoo.
  • Odoo callback login — User login for the backend to connect back to Odoo (e.g. admin).
  • Odoo callback API key — Generate in Odoo: Users → your user → Account Security → New API Key. The backend uses this to write the summary and sub-tasks; you do not share your password.
  • Auto-trigger on assignment — Enable or disable the automation when a user is assigned.
  • LLM Provider — OpenAI, Azure OpenAI, or Ollama (configuration is on the backend).

Requirements

  • Odoo 16.0, 17.0 or 18.0 with Project and Automation modules.
  • A running instance of the AI Task Assistant Backend (FastAPI) with a valid LLM API key.
